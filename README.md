# AMI · Additive Manufacturing Intelligence

The public page of AMI, a web app that learns how additive-manufacturing process settings drive the properties of
printed parts and predicts them with their uncertainty: https://maxfu-uw.github.io/AMI/

This repository holds the page only (index.html and its images). The app's source code and datasets are not published.
